# Volkswagen Araç Satış Otomasyonu

Bu proje, C# Windows Forms ve Entity Framework kullanılarak geliştirilmiş bir araç satış ve müşteri yönetim otomasyonudur. Uygulama, Volkswagen marka araçların satış süreçlerini, müşteri kayıtlarını ve satış istatistiklerini takip etmeyi sağlar.

## 🚀 Teknolojiler
* **Dil:** C#
* **Arayüz:** Windows Forms Application
* **ORM:** Entity Framework
* **Veritabanı:** SQL Server 

## 📋 Temel Özellikler

* **Müşteri Yönetimi:** İsim, soyisim, e-posta ve telefon bilgileriyle sisteme yeni müşteri ekleme, mevcut müşterileri güncelleme, silme ve listeleme işlemleri yapılabilmektedir.
* **Satış İşlemleri:** Sisteme kayıtlı müşteriler listesinden seçim yaparak, belirlenen araç modellerinin (örneğin; Golf, T-Cross, Golf SportWagen) satış kaydı oluşturulabilmektedir.
* **Detaylı Listeleme:** Yapılan satışlar; müşteri adı, soyadı, ürün adı, fiyatı ve araç kategorisi (Hatchback, SUV, Station Wagon vb.) bilgileriyle birlikte tablo halinde görüntülenmektedir.
* **İstatistik ve Analiz:** Sistem üzerinden aşağıdaki istatistiksel verilere anlık olarak ulaşılabilmektedir.
  * En çok araba alan müşteri
  * En çok para harcayan müşteri
  * En az para harcayan müşteri
  * En çok satılan kategori
